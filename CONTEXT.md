# Israeli Health Scrapers

The domain language of this library: scraping Israeli health funds, and the
calibration workflow by which a fund's pages are turned into selectors and tests.

## Funds

**Fund**:
An Israeli health fund (kupat holim) — Maccabi, Clalit, Meuhedet, Leumit. One
scraper file per fund.
_Avoid_: Provider, kupah, insurer, HMO.

## Calibration

**Calibration**:
The act of teaching the library to read a fund — resolving its real login flow and
page structure into selectors, parsers, and tests. Splits into two modes of one
tool: login-calibration and extraction-calibration.
_Avoid_: Configuration, setup, scraping (scraping is the runtime act; calibration
is the authoring act that precedes it).

**Extraction-calibration**:
Calibrating how data is read off an already-authenticated page — the `selectors`,
parser, and any interaction function for one page.

**Login-calibration**:
Calibrating a fund's login flow into its `getLoginOptions` state machine, from an
ordered set of login-screen snapshots. Only its happy path is captured; failure
outcomes are authored speculatively and refined through diagnostics.

**Target**:
The operation being calibrated: `login`, or a fetch target (`medications`,
`appointments`, `testResults`, `vaccinations`, `messages`). Chosen per snapshot via
the capture button's picker, not per run — one session can span several targets.
_Avoid_: Operation, page, section.

**Provisional target**:
A target typed into the capture picker's free-text escape that the `FetchTarget`
union does not model yet (e.g. `form17`). Recorded in the manifest as unmodeled;
reconstruction promotes it into the union, a result type, a `fetch<Target>()`
method, and a fixture dir. Its label must be a lowerCamel slug so it can legally
become both. Until promoted, its flow view renders screens with bindings marked
pending.

**Capture session**:
One run of the capture tool: a human logs into a fund by hand in a headed browser,
drives every reveal (expanding, scrolling, clicking into detail), and records a
series of snapshots. A single session for a new fund can cover both login and
extraction.
_Avoid_: Recording, trace, session (session alone means the encrypted cookie jar —
see below).

**Snapshot**:
The rendered state of one page at one moment, recorded under a chosen label:
`outerHTML` (with input values stripped) + screenshot + URL. Interaction-revealed
data is captured as two snapshots — a before state and an after state.
_Avoid_: Dump (dump means the diagnostics artifact), page, capture.

**Capture manifest**:
The record written by a capture session tying each snapshot label to its URL, its
page, and its role (a before/after pair, a list/detail pair, or an ordered login
screen). It is what lets reconstruction know which snapshots belong together.

**Reconstruction**:
The agent-side step that reads a capture session's raw snapshots and manifest and
hand-authors the committed artifacts: fund-file selectors and parsers, sanitized
fixtures, and DOM tests. Raw snapshots are a private reference, never committed.

**Fixture**:
A small, hand-authored, public-safe HTML file under `test/fixtures/<fund>/` that
reproduces a page's real structure with invented placeholder data and deliberately
seeded edge cases. A reconstruction of a snapshot, never a scrubbed copy of one.
_Avoid_: Sample, mock, snapshot.

**Flow view**:
An on-demand HTML report that replays a calibrated flow as an ordered sequence of
screens, generated by running the *current* fund selectors and parser against a
capture session's snapshots. Each step shows the screenshot, the bindings that
resolved (selector → field/button/parsed value), and the step's result (a login
outcome marker, or the rows a parser extracted). A binding that resolves to nothing
against its screenshot is how it doubles as a drift check.
_Avoid_: Replay, preview, demo.

## Runtime artifacts

**Session**:
The per-fund, encrypted cookie jar that lets a run skip a fresh SMS login. Distinct
from a *capture session*.
_Avoid_: Cookies, token, credentials.

**Diagnostics dump**:
Page HTML + screenshot the scraper writes on a selector-drift or unresolved-login
*failure* at runtime. The input to re-calibration — first-time calibration and
later drift re-enter the same loop through it.
_Avoid_: Snapshot, capture, log.

**Selector drift**:
A previously-working selector no longer matching, because the fund changed its
markup. The failure mode calibration exists to fix.
